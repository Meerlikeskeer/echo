# WEB-017 — Lecture note guide

**Branch:** `feat/WEB-017-lecture-notes` · **Base:** `main` @ `5b47990`

WEB-016 makes Echo record a lecture. This makes the notes worth reading afterwards. They are separate branches because they are separate reviews: one is capture, one is the notes contract and its provider prompt.

## What is wrong today

**A lecture cannot reach the notes endpoint at all.** `isRevisionInput` refuses a transcript over 24,000 characters with `400 bad_request`, and an hour of speech is roughly 55,000. So the endpoint that exists to summarise a session refuses the only session anyone wants summarised.

**Where it does not refuse, it truncates in silence.** `generateNotes` and `generateArtifacts` both do `transcript.text.slice(0, MAX_TRANSCRIPT_CHARS)`. Nothing tells the owner that the notes describe the first twenty minutes of a fifty-minute lecture. That is worse than refusing.

**The artifact schema is a meeting summary.** Title, summary, key points, action items, research topics. A lecture has an argument, terminology used in a particular way, worked examples, and things the lecturer flagged as unresolved or examinable. Bulleted key points flatten all of that into the same shape.

**Gaps are known and thrown away.** The endpoint receives the stitched transcript's `gaps` and uses them only to compute the revision. If four minutes of audio are missing, the notes should say so rather than reading as though the lecture were continuous.

## What this task changes

- Raise the transcript bound to a lecture-sized one, and **refuse rather than truncate** past it. Silent truncation is the defect; a bigger number that still truncates silently is the same defect further away.
- Extend `SessionArtifacts` with what a lecture note guide needs: the course or subject if it can be identified, an outline of sections with the notes under each, terminology as the speaker used it, and open questions the lecture left unresolved.
- Pass the transcript's gaps into the generator so the notes can name them.
- Set `maxDuration` on both route handlers.

## Vendor

None of this picks a vendor. The adapter is OpenAI-compatible and the endpoint is an environment variable, so a large-context model is a configuration change the owner makes in Vercel — recorded here, not hard-coded.
