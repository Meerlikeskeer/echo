# ENG-014 — Stop STATUS.md from causing merge conflicts

**Branch:** `eng/ENG-014-status-per-task-files` · **Base:** `docs/DOC-004-deployed-check-passes` @ `96a1b2a`, **not `main`** — declared below.

## What is being attempted

Remove the three places in `STATUS.md` that every task is required to rewrite, so following the update protocol stops forcing collisions between parallel branches.

1. **In flight** → this directory, one file per task. Done.
2. **The verification snapshot** → the *floor* stays in `STATUS.md` and changes rarely and deliberately; per-run numbers move to the task's own file here and to the pull request body.
3. **The task table** → generated from the `**Status:**` lines already in `TASKS.md` by `scripts/status-table.mjs`, and checked by `npm run check`, so nobody hand-edits a shared table again.

Recorded as **ADR-015**, because `STATUS.md`'s shape is an accepted convention and changing it silently would be reversing a decision without saying so.

## Why the base is not `main`

`main` does not yet have DOC-004 or ENG-013 (pull requests #20 and #19, both open and mergeable). Restructuring `STATUS.md` from `main` would conflict with both of them across most of the file — which is the exact problem this task exists to remove, and a fourth instance of it. Stacking is declared here and in the pull request body per `AGENTS.md`.

**Merge order: #19, then #20, then this one.** Merging the first two before reviewing this one makes this pull request a much smaller diff to read.
