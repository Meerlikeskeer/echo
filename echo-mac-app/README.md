# Echo Mac app

This folder reserves the location of Echo's future native Mac application.
There is no runnable application or chosen native framework here yet.

The intended first version receives recordings from the Echo device and coordinates
transcription, with normal Mac application installation and launch behavior.
Transport, durable storage, transcription execution and native technology choices
must be specified in a dedicated task before implementation. No framework is selected
by this repository reorganization.

The current browser application is in `../echo-web-app`; the ESP32 diagnostics
firmware is in `../echo-device`. See the root ARCHITECTURE.md and DECISIONS.md.
